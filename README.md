## 🚀 Quick Start

## 📚 API Documentation

### 📡 Wikipedia REST API `(id.wikipedia.org)`

```
Base URL: https://id.wikipedia.org/api/rest_v1
```

#### 📋 GET /page/summary/{title}

Ambil ringkasan artikel dalam Bahasa Indonesia.

```bash
# Request
curl https://id.wikipedia.org/api/rest_v1/page/summary/Indonesia

# Response (JSON)
{
  "title": "Indonesia",
  "extract": "Indonesia adalah negara kepulauan terbesar di dunia...",
  "thumbnail": { "source": "https://upload.wikimedia.org/..." },
  "description": "Negara di Asia Tenggara"
}
```

#### 📄 GET /page/html/{title}

Ambil konten HTML lengkap artikel.

```bash
curl https://id.wikipedia.org/api/rest_v1/page/html/Indonesia
```

#### 📰 GET /feed/featured/{year}/{month}/{day}

Konten unggulan harian.

```bash
curl https://id.wikipedia.org/api/rest_v1/feed/featured/2026/05/14
```

### 🔎 Wikimedia Search API

```
Base URL: https://id.wikipedia.org/w/api.php
```

#### 🔍 Search Artikel

| Parameter | Value | Deskripsi |
|-----------|-------|-----------|
| `action` | `query` | Module query |
| `list` | `search` | Search list |
| `srsearch` | `{query}` | Kata kunci pencarian |
| `srlimit` | `20` | Jumlah hasil (max 50) |
| `format` | `json` | Format response |

```bash
curl "https://id.wikipedia.org/w/api.php?action=query&list=search&srsearch=matematika&format=json&origin=*"
```

#### 💡 Autocomplete / OpenSearch

```bash
curl "https://id.wikipedia.org/w/api.php?action=opensearch&search=mate&limit=5&format=json&origin=*"
# Response: ["mate", ["Matematika", "Materi", ...], ...]
```

#### 📂 Category Members

```bash
curl "https://id.wikipedia.org/w/api.php?action=query&list=categorymembers&cmtitle=Category:Fisika&cmlimit=20&format=json&origin=*"
```

## ⚡ Performance Optimization

| Teknik | Implementasi | Dampak |
|--------|-------------|--------|
| 🎨 **CSS Custom Properties** | Design tokens reusable | ⚡ Mengurangi redundancy |
| 🔗 **Preconnect** | Hubungkan dulu ke CDN | ⚡ 200ms lebih cepat |
| 🖼️ **Lazy Loading** | `loading="lazy"` pada gambar | ⚡ Hanya muat saat perlu |
| ⌨️ **Debounce** | Timer 400ms pada search | ⚡ Kurangi API call |
| 🔄 **Async/Await** | Non-blocking requests | ⚡ UI tetap responsif |
| 🏗️ **Minimal DOM** | Reuse elements | ⚡ Render lebih cepat |
| 💾 **localStorage** | Cache bookmark & history | ⚡ Offline-capable |
| 💀 **Skeleton** | Shimmer loading effect | ⚡ Persepsi cepat |
| 🎯 **Semantic HTML** | Proper heading & ARIA | ⚡ SEO + Accessibility |
| 📱 **Mobile First** | Responsive breakpoints | ⚡ Performa mobile |
